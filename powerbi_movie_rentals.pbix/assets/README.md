# Power BI | Movie Rental Store Operations & Customer Analytics

## 📋 Overview
This Power BI project presents an operational and customer performance dashboard for a commercial movie rental store system ("Arianna Movie"). 

The dashboard provides executive-level visibility into key business drivers, including payment trends, rental duration, customer segmentation, and store-level return metrics.

---

## 🎯 Key Features & Dashboard Modules
- **General Rentals & Payments:** Overview of core financial performance and transactional metrics.
- **Returns Analysis:** Operational tracking of average usage days, return percentages, and weekly return distributions per store branch.
- **Movie & Genre Performance:** Rental volume breakdowns across film categories and catalogs.
- **Customer Segmentation:** Behavioral user grouping and demographic rental patterns.

---

## 🛠️ Tech Stack & Skills
- **Business Intelligence Tool:** Power BI Desktop
- **Data Transformation:** Power Query (M) for data cleaning, column standardization, and schema structuring.
- **Analytics:** Custom DAX measures for aggregations, return averages, and percentage metrics.
- **Visual Design:** Custom theme palette, custom cards, and navigation buttons.

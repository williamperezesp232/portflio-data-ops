# Northwind Data Analysis & Operations SQL
This repository contains complex SQL queries designed to extract operational insights and perform sales performance analyses on the **Northwind** database using **PostgreSQL**.

## 📌 Project Overview
The queries in this repository focus on key data analysis techniques including:
- **Relational Joins (`INNER JOIN`, `LEFT JOIN`):** Combining product, sales, customer, and category data.
- **Aggregations & Grouping (`SUM`, `COUNT`, `GROUP BY`):** Calculating total revenue and key performance metrics by product category.
- **Window Functions (`RANK`, `PARTITION BY`, `EXTRACT`):** Ranking sales performance across categories, analyzing yearly order distributions, and running time-based analytics.

## 🛠️ Tools & Environment
- **Database Management System:** PostgreSQL
- **SQL Client:** Visual Studio Code
- **Dataset:** Northwind Sample Database

## 📁 Repository Structure
- `northwind_joins_and_window_functions.sql`: Main SQL script containing grouped analytical queries, order insights, and windowing metrics.

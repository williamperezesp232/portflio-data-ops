# Supply Chain & Northwind Data Analysis (DataOps)

This repository contains SQL queries designed to analyze operational efficiency, supply chain metrics, and sales performance using **PostgreSQL** and **DBeaver**.

## 📌 Project Overview
The analytical queries in this repository focus on end-to-end operational insights across sample databases (**Northwind** and **Supply Chain**), covering:
- **Relational Joins (`INNER JOIN`, `LEFT JOIN`):** Multi-table queries linking products, orders, customers, and inventory data.
- **Aggregations & Grouping (`SUM`, `COUNT`, `GROUP BY`):** KPI calculations, revenue per category, and supply chain volume analysis.
- **Window Functions (`RANK`, `PARTITION BY`, `EXTRACT`):** Ranking performance metrics, yearly trend comparisons, and time-based order distributions.

## 🛠️ Tools & Environment
- **Database Management System:** PostgreSQL
- **SQL Clients:** DBeaver / Visual Studio Code
- **Databases Analyzed:** Supply Chain Database & Northwind Sample Dataset

## 📁 Repository Structure
- `northwind_joins_and_window_functions.sql`: Main SQL script containing queries, operational joins, and windowing analytics.
